# Пакет данных для лабораторной работы 2

Тема: расчет климатических индексов и прогнозирование временного ряда SPEI3.

## Состав

- `data/source/` - исходные и промежуточные климатические данные:
  `climate_data_rapidapi.csv`, данные станции `17150`, результаты обработки RP5,
  месячная таблица SPI/SPEI-3 и Excel-версия.
- `data/indices/` - рассчитанные индексы:
  `indices_station_17150.csv` для одной станции и `spei_all_stations.csv` для всех станций.
- `data/forecast/` - результаты прогнозирования SPEI3:
  прогнозы ARIMA, SARIMA, XGBoost, LSTM, будущий прогноз, метрики, статистика и сводки моделей.
- `figures/` - графики для отчета и веб-приложения.
- `code/` - скрипты и ноутбук, которыми можно воспроизвести подготовку данных.
- `report/` - готовый отчет в DOCX и PDF.
- `manifest.json` - перечень файлов пакета с размерами.

## Ключевые файлы для задания

- `data/indices/indices_station_17150.csv` содержит SPI3, SPI6, SPI9, SPI12,
  SPEI3, SPEI6, SPEI9, SPEI12, SSFI3 и SGI3 для одной станции.
- `data/indices/spei_all_stations.csv` содержит SPEI3, SPEI6, SPEI9, SPEI12 для всех станций.
- `data/forecast/lab2_forecasts.csv` содержит фактические значения, прогнозы и остатки моделей.
- `data/forecast/lab2_metrics.csv` содержит RMSE, MAE, MAPE и R2.

## Проверка

Пакет сформирован из рабочих файлов проекта Django и дополнительных RP5-расчетов.
Для повторного расчета можно запустить `code/lab2_generate_results.py` из корня проекта.
