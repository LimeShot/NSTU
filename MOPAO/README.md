## Структура данных

По структуре первой лабораторной рабочие данные Django лежат в `siteChumakov/chumakov/static/data/`.

В этой папке оставлены только данные, которые нужны для лабораторных 1 и 2:

- `climate_17150.csv`, `climatdata_GTK.csv` — исходные данные станции и рассчитанный ГТК для лабораторной 1.
- `climate_data_rapidapi.csv` — исходный климатический набор для расчета индексов.
- `indices_station_17150.csv`, `spei_all_stations.csv` — результаты расчета SPI/SPEI/SSFI/SGI.
- `lab2_*` — прогнозы, метрики, статистика и текстовые сводки моделей для лабораторной 2.
